# WAEL — Cybersecurity Engineering Portfolio

Static GitHub Pages portfolio.

## Deploy
1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload these files.
3. GitHub → Settings → Pages → Deploy from branch → `main` / root.
4. Replace placeholder GitHub, LinkedIn and email links.
5. Replace the CSS-generated visual placeholders with your real lab screenshots and architecture images.

The design is intentionally evidence-driven: projects, architecture, labs, and technical proof come before generic résumé text.
